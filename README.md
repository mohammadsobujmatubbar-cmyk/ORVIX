# ORVIX

Universal Smart Home Android Platform.

## Technology
- Kotlin
- Jetpack Compose
- MVVM architecture (planned)
- Room Database
- ESP32 Master/Gateway
- ESP8266 Controllers
- LAN UDP and MQTT over TLS
- JSON and configurable custom messages

## Build
APK builds run on GitHub Actions.
No local Android build is required.

## Project status
Initial Android application foundation.
